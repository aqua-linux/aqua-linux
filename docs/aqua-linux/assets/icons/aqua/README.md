# Aqua Core Icons

These project-authored SVGs are the permanent core application and status
icons packaged by Aqua Linux. They use a 64 x 64 view box, round joins, flat
colors, and no gradients. The set is licensed under the adjacent MIT license.

The icons were drawn for this repository. They are not extracted from private
reference boards or copied from another desktop environment.

New artwork must follow the exact filenames, delivery order, and SVG contract
in [`../../../icon-production.md`](../../../icon-production.md). The list is
an owner-production handoff, not permission to source matching artwork from a
third-party icon theme.
